# Requirements

## Required Dependencies

- **Azure CLI** (required)
- **Python 3** (required)
- **jq** (required)
- **curl** (required)
- **unzip** (required)
- **git** (required)
- **pip3** (required)

## Optional Dependencies

- **Docker** (optional, required only for Prowler integration path)
- **ScoutSuite (`scoutsuite` Python package)** (optional, required only for ScoutSuite integration path)
- **Cloudsplaining (`cloudsplaining` Python package)** (optional/future; install only if your team enables related workflow)

## Notes

- The core assessment script can run without optional integrations.
- Missing optional tooling should be documented in engagement notes so report consumers understand evidence scope.
